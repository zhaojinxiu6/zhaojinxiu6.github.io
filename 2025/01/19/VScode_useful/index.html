VScode快捷键

发表于2025-01-19|更新于2026-01-16|学习
|总字数:503|阅读时长:1分钟|浏览量:

VS code 快捷键：

  • alt + shift + f 格式化代码
  • alt + shift + a 单块注释
  • alt + 鼠标左键，多出光标同时操作
  • ctrl + shift + L 重命名变量
  • alt + shift + P 打开 VScode 的命令面板
  • ctrl + shift + V 打开 markdown 预览（需要装插件）
  • alt + Z 自动换行
  • alt + <- 快速回到上次编辑的位置
  • alt + -> 快速回到下次编辑的位置

基本编辑

  • 复制行向下：Shift + Alt + ↓
  • 复制行向上：Shift + Alt + ↑
  • 移动行向下：Alt + ↓
  • 移动行向上：Alt + ↑
  • 删除行：Ctrl + Shift + K
  • 插入行下方：Ctrl + Enter
  • 插入行上方：Ctrl + Shift + Enter
  • 跳到行首/行尾：Home / End
  • 跳到文件开头/结尾：Ctrl + Home / Ctrl + End
  • 注释/取消注释当前行：Ctrl + /
  • 块注释：Shift + Alt + A
  • 选择下一个匹配项：Ctrl + D
  • 选择所有匹配项：Ctrl + Shift + L

导航

  • 快速打开文件：Ctrl + P
  • 跳转到符号：Ctrl + Shift + O
  • 跳转到定义：F12
  • 跳转到声明：Ctrl + F12
  • 查看定义：Alt + F12
  • 返回上一个位置：Alt + ←
  • 前往下一个位置：Alt + →

查找和替换

  • 查找：Ctrl + F
  • 替换：Ctrl + H
  • 在所有文件中查找：Ctrl + Shift + F
  • 在所有文件中替换：Ctrl + Shift + H

文件和窗口管理

  • 新建文件：Ctrl + N

  • 打开文件：Ctrl + O

  • 保存文件：Ctrl + S

  • 全部保存：Ctrl + Shift + S

  • **关闭编辑器

  • 关闭编辑器：Ctrl + F4

  • 关闭所有编辑器：Ctrl + K, Ctrl + W

  • 切换编辑器：Ctrl + Tab / Ctrl + Shift + Tab

  • 切换窗口：Alt + Tab

  • 拆分编辑器：Ctrl + \\

  • 侧边栏显示/隐藏：Ctrl + B

  • 显示资源管理器/文件浏览：Ctrl + Shift + E

  • 显示搜索：Ctrl + Shift + F

终端和调试

  • 打开/关闭终端：Ctrl + ```
  • 创建新终端：Ctrl + Shift + ```
  • 开始/继续调试：F5
  • 停止调试：Shift + F5
  • 步入：F11
  • 步过：F10
  • 步出：Shift + F11

代码格式化

  • 格式化文档：Shift + Alt + F
  • 格式化选定代码：Ctrl + K, Ctrl + F

其他

  • 命令面板：Ctrl + Shift + P
  • 切换全屏：F11
  • 切换Zen模式：Ctrl + K, Z
